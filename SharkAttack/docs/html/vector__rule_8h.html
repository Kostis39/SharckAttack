Structures de données

struct  VectorRule
 Structure représentant un vecteur de poids pour les règles de comportement. La taille du tableau est définie par la valeur de l'énumération Rules_Lenght dans config.h. Ce vecteur permet de stocker et de manipuler de manière générique les composantes liées aux différentes règles. Plus de détails...
