float max_length )

Fonction qui limite la longueur d'un vecteur à une valeur maximale donnée. Si la longueur du vecteur dépasse cette valeur, le vecteur est normalisé et mis à l'échelle pour correspondre à la longueur maximale. Si la longueur du vecteur est inférieure ou égale à la longueur maximale, le vecteur est retourné inchangé.

max_lengthLa longueur maximale autorisée pour le vecteur
Returns
