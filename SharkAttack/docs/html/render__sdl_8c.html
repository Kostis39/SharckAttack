SDL_Rect zone,

affiche WINNER ou LOSER avec un filtre transparent.

Le fond du jeu reste visible derriere.

Si is_winner = 1 : affiche seulement WINNER. Si is_winner = 0 : affiche LOSER et le nombre de poissons restants.

Paramètres
rrenderer SDL utilise pour dessiner
zonezone de l'ecran ou afficher le resultat
is_winner1 si le joueur est gagnant, 0 sinon
remainingnombre de poissons restants pour le perdant
