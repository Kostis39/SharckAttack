bool NewState ( Cell * c,
int nbNeightbors )

Détermine le nouvel état d'une cellule selon les règles du Jeu de la Vie.

Règles de Conway :

  • Une cellule vivante survit si elle a 2 ou 3 voisins vivants.
  • Une cellule morte naît si elle a exactement 3 voisins vivants.
  • Sinon, la cellule meurt ou reste morte.
Parameters
cPointeur vers la cellule courante.
nbNeightborsNombre de voisins vivants.

true si la cellule sera vivante à l'itération suivante, false sinon.
